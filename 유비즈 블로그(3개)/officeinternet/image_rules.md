## 썸네일 방향
질문형·정보형 문구를 사용합니다.

모든 썸네일은 참고 이미지처럼 모바일 화면에서도 즉시 눈에 띄도록 제작합니다.

- 핵심 제목은 굵고 큰 글자로 2~3줄 이내에 배치
- 핵심 키워드는 밝은 형광색이나 보조색으로 강조
- 메인 제목은 흰색 또는 고대비 색상을 사용해 가독성 확보
- 배경 사진은 어둡게 보정하거나 흐림 처리해 문구가 먼저 보이게 구성
- 테두리·색상 배너·굵은 외곽선 등을 활용해 주목도 강화
- 하단 배너에는 필요한 경우 짧은 보조 문구 또는 `070-4707-3333`을 배치
- 한 장에 메시지를 하나로 제한하고, 작은 글자나 복잡한 장식은 사용하지 않음
- 게시물별 구성은 달리하되 색상·서체·전화번호 표기는 일관되게 유지

예:
- 인테리어 전 인터넷 준비 / 왜 먼저 해야 할까요?
- 신규 매장 인터넷 / 언제 확인해야 할까?

## 상품 설명 원고만 있는 경우
- 첨부 이미지 없이 상품 설명 원고만 제공되면 임의의 현장사진이나 제품 이미지를 생성하지 않음
- 원고에서 고객이 꼭 알아야 할 핵심 내용·장점·주의사항·신청 절차 등을 추출
- 강조할 내용을 짧은 문구와 아이콘으로 구성한 본문용 정보 카드 이미지로 제작
- 한 이미지에는 핵심 메시지 하나만 배치해 모바일에서도 쉽게 읽히도록 구성
- 카드 이미지는 같은 게시물과 기존 오피스인터넷 블로그의 색상·서체·배너 구성을 일관되게 유지
- 썸네일은 기존 규칙대로 굵고 눈에 띄는 제목을 사용


## 이미지 파일명 규칙

- 모든 대표 썸네일과 본문 이미지 파일명은 **영문 소문자**로 저장한다.
- 영문 소문자, 숫자, 하이픈(`-`)만 사용한다.
- 단어 구분은 하이픈을 사용하고 공백, 한글, 밑줄, 괄호 및 기타 특수문자는 사용하지 않는다.
- 확장자도 소문자로 통일한다. 예: `.jpg`, `.png`, `.webp`
- 게시 순서를 표시할 때는 두 자리 숫자를 앞에 붙인다.
- ZIP 파일과 Git 저장소에 올리는 이미지도 동일한 영문 파일명을 그대로 유지한다.
- 예: `01-thumbnail.jpg`, `02-fiber-entry-check.jpg`, `03-ap-location-plan.png`


## 상품 설명 카드뉴스 디자인
첨부 이미지가 없는 상품 설명 원고는 위 정보 카드 원칙과 함께 다음 형식을 적용합니다.

- 첨부 참고 이미지처럼 표지형, 큰 제목과 이미지형, 여러 항목을 정리한 그리드형 중 내용에 맞는 구성을 선택
- 표지형은 어두운 사진 오버레이 위에 작은 분류 문구, 굵고 큰 제목, 짧은 보조 설명을 배치
- 본문형은 밝은 배경에 큰 제목, 둥근 모서리의 보조 이미지, 2~3줄의 짧은 설명으로 구성
- 그리드형은 연관된 핵심 내용을 둥근 카드 2~3개로 나누고 이미지·소제목·짧은 설명을 함께 배치
- 흰색이나 연한 배경, 검은색 굵은 제목, 절제된 포인트 색상과 충분한 여백을 사용
- 한 카드에는 핵심 메시지 하나만 담고 모바일에서 쉽게 읽히도록 문장을 짧게 작성
- 보조 이미지는 이해를 돕는 용도로만 사용하며 실제 현장사진이나 실제 제품사진으로 오해할 표현은 사용하지 않음
- 같은 원고의 모든 카드는 색상·서체·간격·모서리·이미지 비율을 통일
- 오피스인터넷 채널 표기와 기존 썸네일 규칙을 그대로 유지
