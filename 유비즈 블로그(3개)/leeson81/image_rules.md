## 썸네일 제작 기준

모든 썸네일은 사용자가 제공한 참고 이미지처럼 모바일 화면에서도 즉시 눈에 띄도록 제작합니다.

- 주제와 직접 관련된 실제 현장사진 또는 현장감 있는 배경을 사용
- 핵심 제목은 굵고 큰 한글로 배치
- 문구는 한눈에 읽히는 2~3단 구조로 구성
- 배경과 글자의 명암 대비를 강하게 적용
- 핵심 단어에는 밝은 강조색을 사용
- 글자 외곽선과 그림자를 적용해 작은 화면에서도 가독성 확보
- 불필요한 문구는 줄이고 핵심 내용만 짧게 표현
- 상단에는 **기업인터넷**, 하단에는 **070-8277-7777** 표기
- 썸네일마다 배경과 구도는 달리하되 전체적인 브랜드 분위기는 통일
- 과도하게 인공적인 느낌보다 실제 설치·상담 현장처럼 자연스럽게 표현

### 한글 문구 품질

- 생성형 이미지 안에 한글 문구를 직접 생성하지 않음
- 배경 이미지를 먼저 만든 뒤 정확한 한글 제목을 별도로 합성
- 완성 전 오탈자, 글자 깨짐, 전화번호 오류를 반드시 확인
