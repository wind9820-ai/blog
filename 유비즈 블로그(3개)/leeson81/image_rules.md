# 기업인터넷 이미지 제작 규칙

## 기본

- 1:1 정사각형
- 1200×1200px 이상 권장
- 실제 현장사진 중심
- 썸네일과 본문 이미지는 사용자가 제공한 참고 이미지의 잡지형 편집 디자인을 기준으로 제작
- 같은 게시물의 모든 이미지는 색상·서체·여백·장식 요소를 일관되게 유지

## 공통 디자인 기준

- 밝은 아이보리 또는 연한 회색의 종이 질감 배경을 사용
- 모서리는 부드러운 라운드 형태로 처리
- 상단에는 날짜 또는 카테고리, 가운데 채널명 **기업인터넷**, 우측에는 바코드형 장식 등 잡지 표지 요소를 배치
- 상단 정보 아래에는 가는 검은 구분선을 사용
- 사진은 넓은 여백 안에 배치하고, 종이테이프 또는 컬러 테이프 장식으로 자연스러운 스크랩북 느낌을 표현
- 검정·회색을 기본색으로 사용하고, 갈색 또는 차분한 파란색을 포인트 색상으로 사용
- 장식은 과도하게 사용하지 않고 정보와 현장사진이 먼저 보이도록 구성
- 참고 이미지의 카페명·잡지명·문구를 그대로 복사하지 않고 기업인터넷 주제에 맞게 바꾸어 사용

## 썸네일 제작 기준

- 참고 이미지 1의 잡지 표지형 구성을 기본으로 사용
- 상단에는 날짜·채널명·바코드형 장식과 가는 구분선을 배치
- 중앙에는 주제와 직접 관련된 실제 현장사진을 크게 배치
- 메인 제목은 사진 아래쪽에 크고 눈에 띄게 배치하며 1~2줄로 제한
- 제목은 자연스러운 손글씨 또는 감성적인 편집 서체를 사용하되 모바일에서도 쉽게 읽히도록 제작
- 핵심 단어는 갈색·파란색 등 포인트 색상 또는 영문 보조 표현으로 강조
- 제목 아래에는 게시물 내용을 설명하는 짧은 보조 문구를 1~2줄로 배치
- 사진 모서리에는 테이프 장식을 제한적으로 사용해 잡지·스크랩북 느낌을 유지
- 썸네일마다 사진과 문구는 달리하되 전체 레이아웃과 브랜드 분위기는 통일
- **기업인터넷**과 **070-8277-7777**은 디자인을 해치지 않는 범위에서 정확히 표기

## 본문 이미지 제작 기준

- 참고 이미지 2의 잡지 내지형 구성을 기본으로 사용
- 왼쪽에는 현장사진 또는 제품·설치 관련 사진을 크게 배치
- 오른쪽에는 제목, 짧은 설명, 핵심 정보 또는 강조 내용을 계층적으로 배치
- 제목은 검정 손글씨형 또는 편집 서체로 크게 표시
- 본문 설명은 회색 계열의 읽기 쉬운 글자로 구성하고 너무 길게 넣지 않음
- 핵심 장점·구성·절차·주의사항은 파란색 소제목과 굵은 검정 글자로 강조
- 한 이미지에는 핵심 메시지 하나만 담고, 긴 내용은 여러 장의 카드로 나눔
- 사진의 핵심 장비나 작업 부분을 글자와 장식으로 가리지 않음
- 상단 또는 하단에 **기업인터넷**과 **070-8277-7777**을 작고 일관되게 표기
- 같은 글의 본문 카드들은 동일한 배경·서체·포인트 색상·여백 규칙을 유지

## 한글 문구 품질

- 생성형 이미지 안에 한글 문구를 직접 생성하지 않음
- 배경과 사진 구성을 먼저 만든 뒤 정확한 한글 문구를 별도로 합성
- 완성 전 오탈자, 글자 깨짐, 전화번호 오류를 반드시 확인
- 참고 이미지의 문구를 그대로 사용하지 않고 각 게시물 원고에 맞는 내용으로 작성

## 이미지 파일명 규칙

- 모든 대표 썸네일과 본문 이미지 파일명은 **영문 소문자**로 저장한다.
- 영문 소문자, 숫자, 하이픈(`-`)만 사용한다.
- 단어 구분은 하이픈을 사용하고 공백, 한글, 밑줄, 괄호 및 기타 특수문자는 사용하지 않는다.
- 확장자도 소문자로 통일한다. 예: `.jpg`, `.png`, `.webp`
- 게시 순서를 표시할 때는 두 자리 숫자를 앞에 붙인다.
- ZIP 파일과 Git 저장소에 올리는 이미지도 동일한 영문 파일명을 그대로 유지한다.
