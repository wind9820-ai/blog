## 채널 성격
현장 경험형 / 질문 해결형 / 구성방법 설명형 콘텐츠를 중심으로 합니다.

## 핵심 관점
- 1층과 2층을 한 회선으로 사용할 수 있는지
- 여러 층 Wi-Fi 구성
- AP 배치
- 한 회선 활용 방법
- LAN 포트와 배선
- 현장 구조에 따른 실제 구성

## 문체
