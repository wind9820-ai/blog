# 유비즈 블로그 제작 프로젝트

이 프로젝트는 `../README.md`, `../image_rules.md`, `../post_template.md`의 제작지침을 기준으로
현장 시공사례 중심의 네이버 블로그 원고를 일관되게 제작하기 위한 작업공간입니다.

## 기본 운영 원칙

- 표시 상호: **유비즈**
- 상담: **1661-7372**
- 사이트: **u-biz.co.kr**
- 채널 성격: 현장 시공사례와 구축 과정 중심
- 핵심 관점: 현장 실사, 인터넷·Wi-Fi·네트워크·CCTV 구축, 공정 협의, 고객 맞춤 구성, 진행 과정, 최종 확인
- 문체: 전문적이되 어렵지 않게
- 과장 표현 금지: 실제 확인된 작업과 효과만 작성

## 사용 순서

1. `blog_request_template.md`에 현장 정보를 입력합니다.
2. `production_workflow.md` 순서에 따라 원고를 작성합니다.
3. 사진 사용 시 `../image_rules.md`를 적용합니다.
4. 게시 전 `qa_checklist.md`로 검수합니다.
5. 최종 원고 구조는 `../post_template.md`를 따릅니다.

## 산출물 권장 구성

- 제목 후보 5개
- 최종 제목 1개
- 본문 원고
- 사진별 캡션/삽입 위치
- 썸네일 문구
- 해시태그
- 게시 전 검수 결과
