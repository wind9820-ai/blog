# 게시 전 QA 체크리스트

## 원고
- [ ] 현장 업종, 지역, 공사 단계가 자연스럽게 소개되었는가
- [ ] 고객 요청사항과 실제 작업내용이 구분되어 있는가
- [ ] 현장 실사에서 확인한 내용만 썼는가
- [ ] 인터넷·배선·AP·네트워크·CCTV 등 실제 작업 범위만 설명했는가
- [ ] 공정 협의 내용이 있을 경우 인테리어·전기팀과의 조율 내용을 포함했는가
- [ ] 완료 항목과 진행 중 항목을 구분했는가
- [ ] 확인되지 않은 성능 향상, 비용 절감, 품질 개선 수치를 만들지 않았는가
- [ ] 문체가 전문적이되 어렵지 않은가
- [ ] 유비즈가 현장을 직접 확인하고 공정을 조율하는 전문 업체라는 인상이 자연스럽게 드러나는가

## 이미지
- [ ] 1:1 정사각형 기준을 지켰는가
- [ ] 첨부 사진이 있으면 실제 현장사진을 우선 사용했는가
- [ ] 얼굴, 주소, 전화번호, 차량번호를 확인했는가
- [ ] IP / MAC / S/N / QR / 바코드가 노출되지 않았는가
- [ ] 관리자 계정/비밀번호가 노출되지 않았는가
- [ ] 상단에 '유비즈' 또는 '유비즈 기업통신전담센터'가 표시되었는가
- [ ] 하단에 '1661-7372 · u-biz.co.kr'가 표시되었는가
- [ ] 실제 사진이 있는 경우 문구가 장비·배선·작업영역을 가리지 않는가

## 상품설명 원고용 이미지 카드
- [ ] 첨부 이미지가 없고 상품설명 원고만 있는 경우에 카드 방식으로 제작했는가
- [ ] 본문에서 실제로 강조할 핵심 내용만 골랐는가
- [ ] 카드 1장당 메시지가 1개인가
- [ ] 제목이 1~2줄로 짧은가
- [ ] 원고에 없는 기능·가격·혜택·수치를 추가하지 않았는가
- [ ] 실제 앱 화면·실제 단말·실제 현장으로 오인될 수 있는 가상 이미지를 만들지 않았는가
- [ ] 고품질 실사형 AI 이미지를 불필요하게 제작하지 않았는가

## 썸네일
- [ ] 실제 사진이 있으면 현장 중심, 상품설명 원고만 있으면 카드형으로 구성했는가
- [ ] 제목이 2~3줄 이내인가
- [ ] 흰색·마젠타·짙은 남보라 계열을 기본으로 했는가
- [ ] 과도한 광고 이미지나 3D 렌더 느낌이 없는가

## 마무리
- [ ] 상담번호 1661-7372가 정확한가
- [ ] 사이트 u-biz.co.kr가 정확한가
- [ ] 기본 해시태그가 포함되었는가
