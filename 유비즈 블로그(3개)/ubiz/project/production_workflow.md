# 유비즈 블로그 제작 워크플로

## 1단계. 사실 정리
제공된 현장 정보에서 확인 가능한 사실만 추립니다.
확인되지 않은 속도, 품질 개선 수치, 비용 절감 효과 등은 임의로 만들지 않습니다.

## 2단계. 제목 후보 작성
제목은 현장 유형 + 핵심 작업 + 지역/업종 정보를 자연스럽게 조합합니다.
검색어를 억지로 반복하지 않고, 실제 작업내용이 드러나게 작성합니다.

예시 구조:
- [업종] 매장 인터넷·Wi-Fi 구축 현장
- [지역] 사무실 네트워크 배선 및 AP 설치 사례
- 인테리어 공정과 함께 진행한 매장 통신공사 사례

## 3단계. 본문 작성
다음 흐름을 기본으로 합니다.

1. 도입부
2. 고객 요청 또는 문제
3. 현장 확인
4. 작업 과정
5. 공정 협의
6. 현재 결과 또는 진행상황
7. 이용자 관점 효과
8. 마무리

문장은 전문적이되 현장 경험이 없는 독자도 이해할 수 있게 씁니다.

## 4단계. 이미지 구성

### 첨부 이미지가 있는 경우
실제 현장사진 중심으로 구성합니다.
본문 이미지는 장비·배선·작업영역을 가리지 않게 설명 문구를 배치합니다.

가림 대상:
- 얼굴
- 정확한 주소
- 개인 전화번호
- 차량번호
- IP / MAC / S/N
- QR / 바코드
- 관리자 계정 / 비밀번호

### 첨부 이미지가 없고 상품설명 원고만 있는 경우
고품질 실사형 이미지를 새로 만드는 대신, 본문에서 강조해야 할 내용을 이미지 카드로 제작합니다.

- 본문 핵심 포인트를 4~6개 정도 선별
- 카드 1장당 핵심 메시지 1개
- 제목은 1~2줄로 짧게
- 원고에 없는 기능·수치·혜택은 추가하지 않음
- 단순 아이콘·도형·추상 배경을 활용 가능
- 실제 앱 화면·실제 단말·실제 고객 현장처럼 보이게 만들지 않음

## 5단계. 썸네일
- 1:1 정사각형
- 실제 사진이 있으면 현장 사례 중심
- 상품설명 원고만 있으면 카드형 썸네일
- 제목 2~3줄 이내
- 유비즈 기존 썸네일과 연결감 있는 짙은 남색 + 민트 포인트 + 흰색 제목 구성
- 과도한 광고사진·3D 렌더 느낌 금지
