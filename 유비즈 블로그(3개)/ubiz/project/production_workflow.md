# 유비즈 블로그 제작 워크플로

## 1단계. 사실 정리
제공된 현장 정보에서 확인 가능한 사실만 추립니다.
확인되지 않은 속도, 품질 개선 수치, 비용 절감 효과 등은 임의로 만들지 않습니다.

## 2단계. 제목 후보 작성
제목은 현장 유형 + 핵심 작업 + 지역/업종 정보를 자연스럽게 조합합니다.
검색어를 억지로 반복하지 않고, 실제 작업내용이 드러나게 작성합니다.

예시 구조:
- [업종] 매장 인터넷·Wi-Fi 구축 현장
- [지역] 사무실 네트워크 배선 및 AP 설치 사례
- 인테리어 공정과 함께 진행한 매장 통신공사 사례

## 3단계. 본문 작성
다음 흐름을 기본으로 합니다.

1. 도입부
2. 고객 요청 또는 문제
3. 현장 확인
4. 작업 과정
5. 공정 협의
6. 현재 결과 또는 진행상황
7. 이용자 관점 효과
8. 마무리

문장은 전문적이되 현장 경험이 없는 독자도 이해할 수 있게 씁니다.
