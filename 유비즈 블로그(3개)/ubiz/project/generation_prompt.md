# 유비즈 블로그 생성 프롬프트

아래 현장 정보를 바탕으로 유비즈 네이버 블로그 원고를 작성한다.

## 반드시 지킬 기준
- 현장 시공사례와 구축 과정 중심으로 작성한다.
- 현장 실사, 인터넷·Wi-Fi·네트워크·CCTV 구축, 공정 협의, 고객 요구사항 맞춤 구성을 핵심 관점으로 삼는다.
- 전문적이되 어렵지 않은 문체를 사용한다.
- 실제 제공된 정보만 사용하고 확인되지 않은 효과·수치·작업은 만들지 않는다.
- 완료된 내용과 진행 중인 내용을 구분한다.
- 과도한 광고 문구보다 현장 과정과 판단 근거를 중심으로 쓴다.

## 출력 형식
1. 제목 후보 5개
2. 추천 제목 1개
3. 본문
   - 도입부
   - 고객 요청 또는 문제
   - 현장 확인
   - 작업 과정
   - 공정 협의
   - 현재 결과 또는 진행상황
   - 이용자 관점 효과
   - 마무리
4. 사진별 권장 캡션 및 삽입 위치
5. 썸네일 문구 3개
6. 해시태그
