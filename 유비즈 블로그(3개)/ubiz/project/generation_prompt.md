# 유비즈 블로그 생성 프롬프트

아래 현장 정보를 바탕으로 유비즈 네이버 블로그 원고를 작성한다.

## 반드시 지킬 기준
- 현장 시공사례와 구축 과정 중심으로 작성한다.
- 현장 실사, 인터넷·Wi-Fi·네트워크·CCTV 구축, 공정 협의, 고객 요구사항 맞춤 구성을 핵심 관점으로 삼는다.
- 전문적이되 어렵지 않은 문체를 사용한다.
- 실제 제공된 정보만 사용하고 확인되지 않은 효과·수치·작업은 만들지 않는다.
- 완료된 내용과 진행 중인 내용을 구분한다.
- 과도한 광고 문구보다 현장 과정과 판단 근거를 중심으로 쓴다.
- 첨부 이미지가 없고 상품설명 원고만 있는 경우에는 고품질 실사형 이미지를 새로 만드는 것을 기본 작업으로 두지 않는다.
- 이 경우 본문에서 강조할 핵심 내용을 원고 근거로 선별해 1:1 이미지 카드로 만든다.
- 이미지 카드는 카드 1장당 핵심 메시지 1개, 큰 제목 1~2줄 중심으로 구성하고 원고에 없는 기능·수치·혜택은 추가하지 않는다.

## 출력 형식
1. 제목 후보 5개
2. 추천 제목 1개
3. 본문
   - 도입부
   - 고객 요청 또는 문제
   - 현장 확인
   - 작업 과정
   - 공정 협의
   - 현재 결과 또는 진행상황
   - 이용자 관점 효과
   - 마무리
4. 이미지 구성
   - 첨부 이미지가 있으면 사진별 권장 캡션 및 삽입 위치
   - 첨부 이미지가 없고 상품설명 원고만 있으면 본문 강조 이미지 카드 4~6개 문구와 삽입 위치
5. 썸네일 문구 3개
6. 해시태그
