# 유비즈 이미지 제작 규칙

## 적용 기준
사용자가 제공한 ‘압구정 신규 매장 / 광케이블 인입 실사 / 인터넷·Wi-Fi 구성’ 썸네일의 브랜드 구성을 같은 유비즈 채널에 적용합니다. 다른 채널의 상호·연락처와 혼용하지 않습니다.

## 공통 규격
- 1:1 정사각형, 기본 출력 2000×2000px
- PNG 원본과 업로드용 고화질 JPG를 함께 제공
- 남색 #00142E / 민트 #32F4BB / 흰색 #FFFFFF
- 상단 중앙 남색 둥근 바: **유비즈 기업통신전담센터**
- 하단 중앙 남색 둥근 바: **1661-7372 · u-biz.co.kr**
- 흰색 모서리 프레임과 끝점 원형 장식
- 한글 글자는 이미지에 직접 생성시키지 않고, 검수 가능한 서체로 별도 조판
- 글꼴 파일은 저장소나 배포 패키지에 포함하지 않음

## 대표 썸네일
- 상품 또는 현장과 관련 있는 선명한 사진을 배경으로 사용
- 제목 가독성에 필요한 정도만 남색 계열로 어둡게 보정
- 상단 브랜드 바 아래: 민트색 키워드 박스 + 굵은 남색 글자
- 중앙: 핵심 제목 2줄, 굵은 흰색 글자 + 남색 외곽선
- 핵심 대상이 보이도록 제목 크기와 위치를 조정
- 상호·연락처·프레임 위치는 기존 유비즈 썸네일과 통일
- 다른 글의 지역명·현장명·공사내용은 복사하지 않음

## 본문 이미지
- **설명글, 기능 제목, 헤드라인, 번호 목록, 기능 카드 등은 넣지 않음**
- 이미지 안의 추가 텍스트는 상호와 연락처·사이트만 사용
- 사진 자체가 가장 잘 보이도록 배치
- 썸네일과 같은 남색 브랜드 바와 연락처 바 적용
- 본문 프레임은 썸네일보다 가늘게 사용하고 민트색 끝점으로 연결감 유지
- 설명과 기능 안내는 원고에만 작성

## 사진의 사실성과 출처
- 실제 현장 시공사례는 사용자가 제공한 현장사진을 우선 사용
- 상품소개에 사용하는 스톡 사진은 서비스 이해를 돕는 연출 이미지로 구분
- 스톡 사진을 유비즈의 실제 고객 현장, 제공 단말 모델, AI 비즈콜의 실제 앱 화면이라고 표현하지 않음
- 실제 제공되지 않은 앱 화면·직원정보·전화번호를 만들어 넣지 않음
- 스톡 사진 출처와 라이선스 페이지를 별도 출처 파일에 기록
- 실제 현장사진의 장비·배선·공사 상태를 임의로 변경하지 않음
