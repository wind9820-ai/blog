## 이미지 파일명 규칙

- 모든 대표 썸네일과 본문 이미지 파일명은 **영문 소문자**로 저장한다.
- 영문 소문자, 숫자, 하이픈(`-`)만 사용한다.
- 단어 구분은 하이픈을 사용하고 공백, 한글, 밑줄, 괄호 및 기타 특수문자는 사용하지 않는다.
- 확장자도 소문자로 통일한다. 예: `.jpg`, `.png`, `.webp`
- 게시 순서를 표시할 때는 두 자리 숫자를 앞에 붙인다.
- ZIP 파일과 Git 저장소에 올리는 이미지도 동일한 영문 파일명을 그대로 유지한다.
- 예: `01-thumbnail.jpg`, `02-fiber-entry-check.jpg`, `03-ap-location-plan.png`
