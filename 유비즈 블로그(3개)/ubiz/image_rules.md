# 유비즈 이미지 제작 규칙

## 기본
- 1:1 정사각형
- 1200×1200px 이상 권장
- 실제 현장사진이 있으면 현장사진을 우선 사용
- 자연스러운 스마트폰 현장 기록 느낌 유지
- 고품질 실사형 AI 이미지 제작을 기본 작업으로 요구하지 않음

## 보안
가림 필요:
- 얼굴
- 정확한 주소
- 개인 전화번호
- 차량번호
- IP / MAC / S/N
- QR / 바코드
- 관리자 계정 / 비밀번호

## 실제 사진이 있는 본문 이미지
- 상단: **유비즈**
- 하단: **1661-7372 · u-biz.co.kr**
- 설명 문구: 1~2줄
- 사진의 장비·배선·작업 영역을 가리지 않게 배치
- 실제 없던 장비, 케이블, 설치 결과를 추가하지 않음

## 첨부 이미지가 없는 상품설명 원고
사진이나 이미지 없이 상품설명 원고만 있는 경우에는 본문에서 강조해야 할 내용을 **이미지 카드**로 제작합니다.

- 원고가 실제로 뒷받침하는 핵심 내용만 사용
- 핵심 기능, 이용 방식, 고객 편의, 관리 포인트 등을 우선 선택
- 기본 4~6장 정도로 구성하되 원고 내용이 적으면 억지로 장수를 채우지 않음
- 카드 1장당 핵심 메시지 1개
- 큰 제목은 1~2줄 이내
- 긴 설명문은 넣지 않음
- 필요 시 단순 아이콘, 도형, 추상 배경 사용
- 실제 앱 화면, 실제 단말, 실제 고객 현장으로 오인될 수 있는 가상 이미지는 만들지 않음
- 원고에 없는 기능, 가격, 혜택, 수치, 호환성은 추가하지 않음
- 상단: **유비즈 기업통신전담센터**
- 하단: **1661-7372 · u-biz.co.kr**

## 이미지 카드 문구 예시
본문에 해당 내용이 실제로 있을 때만 아래처럼 짧게 압축합니다.

- 개인번호 노출 없이 / 회사번호로 통화
- 외근 중에도 / 업무전화 확인
- 업무가 끝난 뒤에는 / 수신 조절
- 통화 기록부터 / 업무 정리까지
- 직원이 바뀌어도 / 회사번호는 회사가 관리

## 썸네일
- 실제 현장사진이 있으면 현장 사례 중심
- 상품설명 원고만 있으면 상품 핵심 메시지를 카드형으로 구성
- 제목은 2~3줄 이내
- 유비즈 블로그의 기존 썸네일과 연결감 있게 구성
- 흰색, 민트 포인트, 짙은 남색 계열을 기본으로 활용
- 상단에 유비즈 브랜드, 하단에 **1661-7372 · u-biz.co.kr** 표기
